# Ambxst-Animations-mod

This is a mod for [Ambxst](https://github.com/Axenide/Ambxst) that adds a
Settings page for Hyprland's animation system: bezier curves, spring curves
(Hyprland 0.56+), and per-leaf timings/styles, applied live.

## Installation
To install via settings gui, paste the link 

``` 
https://github.com/Big-mac23/Ambxst-Animations-mod.git
```   

or to install manually
```
ambxst install https://github.com/Big-mac23/Ambxst-Animations-mod.git
ambxst mods enable community.animation-studio
ambxst reload
```
